# SystolicGuard 轻量安全补充功能

安全不是 SystolicGuard 的唯一主线，而是 AI 加速器架构旁路上的补充监控机制。

## 已实现机制

- **计算期写保护**：`busy=1` 时拒绝修改激活、权重和 Bias。
- **粘滞故障记录**：攻击或错误被记录到 `security_fault`，直到执行安全清除。
- **奇偶校验**：写入缓冲区时保存 parity，启动前重新校验；不匹配则拒绝执行。
- **安全清除**：`secure_clear` 清除激活、权重、Bias、输出、PE 状态和故障状态。

| fault_code | 含义 |
|---:|---|
| 0 | 无故障 |
| 1 | 计算期间非法写入 |
| 2 | 缓冲区完整性错误 |

测试平台会模拟计算期间篡改权重和直接翻转权重存储位，证明写入被阻断或执行被拒绝。

## 威胁模型边界

这些机制可演示基础寄存器篡改、故障注入检测和敏感数据擦除，但不能防御功耗/电磁侧信道、时序侧信道、复杂硬件木马或物理探针。不要把教学功能描述为完整安全芯片方案。
